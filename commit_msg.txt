chore(research-integrity): finalise repo foundation and pilot reconciliation

This comprehensive commit finalises the Phase 0 repository foundation, correcting significant methodology assumptions and standardising the experimental baseline ahead of the full experiment suite (E0b-E7).

Precision & Hardware Standardisation (T4 Compatibility):
* Refactored `configs/base.yaml`, `loader.py`, and `qra_pipeline.py` to use `float16` instead of `bfloat16`. Kaggle T4 GPUs (Compute Capability 7.5) do not natively support BF16 tensor core acceleration, causing mismatches between configuration intent and runtime execution.
* Fixed the `certificate.py` silent failure bug that attempted to parse `"bf16"` and `"int4"` keys instead of `"fp16"` and `"nf4"`.
* Updated `pilot_p1_qra_check.py` to use the correct `--skip_fp16` flag.
* Standardised `autocast` blocks in Pilot 3 and Pilot 4 to `torch.float16`.

Methodology Audits & Record Reconciliations:
* QUAIL Implementation Fidelity: Updated evaluation matrix and implementation records to reflect that the current QUAIL loss is an incomplete surrogate containing only the Hinge term. Exposes missing forget/retain terms and non-standard hyperparameters (CR-005).
* SSIUU Attribution Formulation: Documented the critical mathematical disconnect between the published SSIUU paper (parameter-level gradients, HVP, dynamic tracking) and the codebase's surrogate implementation (Captum LayerIG, static baseline, detached gradient flow). This firmly establishes Research Gate RG-001 as BLOCKED.
* Consolidated the unstructured markdown method records into a canonical `handbook/research_gates.yaml` and refactored `scripts/research_gate.py` to parse this structured registry.

Project State & Orchestration:
* Updated `PROJECT_STATUS.md` to reference the correct YAML registry and formally record the P3 verdict as PASS (correcting the gradient norm evaluation criterion).
* Standardised dependency management by dynamically linking `requirements.txt` into `pyproject.toml` (`dynamic = ["dependencies"]`).
* Implemented `experiments/notebooks/kaggle/EXPERIMENT_RUNNER.ipynb` with `DRY_RUN` functionality to safely orchestrate and validate the full E0b-E7 sequence on Kaggle.

The repository is now fully staged for the independent evaluation phase, with all scientific blockers (RG-001, RG-002, RG-003) explicitly registered and isolated.
